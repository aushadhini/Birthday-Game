# Our song lives here

Our song: "Until I Found You" — Stephen Sanchez

Place the MP3 in this folder named exactly:

    until-i-found-you.mp3

That path is already wired up as `musicSrc` in `src/data/config.js`.
To use a different file name or track, update `musicSrc` / `musicTitle` /
`musicArtist` there.

Note: the audio file itself is not included — add your own copy of the track.
